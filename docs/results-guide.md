# 결과 해석 안내 — 국가 Risk Index 정합성 검증 (2025)

이 문서는 내부 실행 후 생성된 HTML·엑셀·그림이 **어떤 절차로 나왔는지**, **어떻게 읽어야 하는지**를 설명한다.  
실데이터 숫자는 넣지 않는다. 산출물 파일만 보면 된다.

**읽을 순서:** HTML 보고서 → `verdicts.xlsx` → `join_coverage.xlsx` / `unmatched_countries.xlsx` → `statistical_results.xlsx` → 그림.

---

## 1. 이 결과가 의미하는 것 / 의미하지 않는 것


| 맞는 표현                                                   | 틀린 표현             |
| ------------------------------------------------------- | ----------------- |
| 현재 국가 RI와 **2025년** 단기수출보험 국별 위험지표의 **정합성 검토**          | 독립적인 예측력 검증       |
| 국가 단위 RI 위험성향과 국가 지표의 관계                                | 국가×업종 RI가 맞다고 검증함 |
| 지표별로 Supported / Partially / Not supported / Untestable | RI 정확도 몇 %        |
| 기대 방향(RI 높을수록 위험지표도 나쁨)이 보이는지                           | RI가 유용하니 도입하라는 결론 |


RI 5 = 고위험, 국가등급 1–7(클수록 고위험)을 전제로 방향을 해석한다.

국별총위험량(`exposure`)은 **참고만** 한다. 국가 규모·포트폴리오 크기의 영향을 받으므로 핵심 판정에 넣지 않았다.

## 2. 결과가 나오기까지의 절차

`python -m src.run_all --config config\analysis_config.json` 한 번의 순서다.

```text
1. RI 월별 xlsx 12개 읽기 (Sheet1, 헤더 2행, A:E, "RI 1"~"RI 5")
2. 검증자료 xlsx 읽기 (시트 단기수출보험, 헤더 3행, F:K만)
3. 국가×업종×월 → 국가×월 → 국가×연도(국가당 1행)
4. 국가한글명으로 조인 (퍼지매칭 없음)
5. 비모수 통계 + 민감도 + 판정
6. PNG 그림 + 오프라인 HTML
```



### 2.1 분석 단위 (가장 중요)

원 RI는 **국가×업종×월**이다. 검증자료는 **국가×2025년 연간 1행**이다.

월별·업종별 행에 연간 타깃을 반복 붙여 표본을 늘리지 않는다. 최종 통계 테이블은 **국가당 한 행**이다.


| 단계      | 하는 일                                           |
| ------- | ---------------------------------------------- |
| 국가×월    | 그달 업종 RI가 모두 같으면 그 값. 섞이면 **중앙값**을 월 RI로 사용    |
| 국가×연도   | 월별 RI의 **연간 중앙값**이 주분석 RI (`ri_annual_median`) |
| 주 분석 국가 | 2025년 **관측 월 ≥ 6**인 매칭 국가                      |


함께 저장만 하는 값: 연간 평균, 최빈값, 최솟값·최댓값, 고위험(RI 4–5) 월 비율, 업종 기준 고위험 비율, RI 변경 횟수.

### 2.2 조인

검증자료에 국가코드가 없어 **국가한글명**으로 붙인다. 공백·줄바꿈·유니코드 정규화만 한다.  
이름이 다르면 `config/country_name_map.json`에만 수동으로 넣는다. 자동 퍼지매칭은 없다.

제외 라벨(기본): `값 없음`, `기타`. 국가등급 0인 집계행 등은 config의 `exclude_country_names`에 추가한 뒤 재실행한 상태여야 한다.

### 2.3 통계 (지표마다 세 겹)

사고율·손해율·실질손해율은 0이 많을 수 있어 상관 하나만 보지 않는다.

1. **전체 국가:** Spearman ρ, 국가 단위 bootstrap 95% CI, RI 수준별 중앙값, Kruskal-Wallis, ε²
2. **발생 여부:** 값이 0보다 큰지 (`has_accident` 등). 결측은 0으로 치지 않음
3. **양수 국가만:** 규모 상관. 양수 국가가 10개 미만이면 이 부분은 Untestable

국가등급은 1–7 순서형으로 Spearman·분포·교차표를 본다.

민감도(판정 안정성 확인용, 유리한 결과만 고르지 않음):

- 12개월 완전 관측만  
- 매칭 국가 전체  
- 연간 중앙값 대신 연간 평균  
- 연간 중앙값 대신 고위험 월 비율

p-value 하나로 결론 내지 않는다. **방향 + CI + 분포/발생률 + 민감도**를 같이 본다.

## 4. HTML을 어떻게 읽나

브라우저로 `risk_index_validation_report.html`만 열면 된다. CDN이 없다.

1. **노란 상자** — 예측 모델 평가가 아님을 고정한다.
2. **§2 분석 단위** — 주 분석 국가 수(`n`)가 이후 표의 분모다. 6개월 미만 국가는 주분석에서 빠진다.
3. **§3 매칭률** — 낮으면 결과가 일부 국가에만 해당한다. `unmatched_countries.xlsx`와 같이 본다.
4. **§5–7 표** — 지표별 n, Spearman ρ, CI, 발생여부 ρ, 판정.
5. **§9 종합 판정 + 한 문장** — 코드가 지표 판정을 모아 고른 문장이다. 이 한 문장만으로 과대 해석하지 말고, 지표별 판정을 먼저 본다.
6. **그림** — 0이 많은 비율은 일반 박스플롯만 보지 말고, 발생률(04–06)과 양수 분포(07)를 분리해서 본다.
